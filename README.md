# Редактор программы ММОМА

Статическая админ-страница для редактирования программы мероприятий и экспорта готового HTML-фрагмента с исходными стилями.

## Возможности

- редактирование вступления и информации о выставке;
- добавление, удаление, копирование и перестановка разделов и событий;
- несколько дат и временных интервалов у одного события;
- живой предпросмотр для компьютера, планшета и телефона;
- автосохранение черновика в `localStorage` браузера;
- резервная копия и восстановление через JSON;
- скачивание готового HTML-фрагмента для вставки на сайт.

## Локальный запуск

Откройте `index.html` напрямую или запустите любой статический сервер, например:

```bash
python3 -m http.server 8080
```

После этого откройте `http://localhost:8080`.

## Публикация на GitHub Pages

В настройках репозитория откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.

> GitHub Pages — статический публичный хостинг. В редакторе нет серверной авторизации, а черновики сохраняются только в браузере пользователя.
